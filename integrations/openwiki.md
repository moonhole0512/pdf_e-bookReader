# OpenWiki Integration

Use this integration only when the target project has OpenWiki, a `.claims/` store, or an explicitly configured equivalent.

- Store codebase architecture, API contracts, invariants, and implementation claims here.
- Ground claims in stable `repo://path#Lx-Ly` references and the relevant commit or source version.
- Update the project's architecture map when data flow or core structure changes.
- Do not create an OpenWiki directory, edit `.claims/`, or run an OpenWiki command merely because this integration file exists.
- Keep OpenWiki code claims separate from LLM Wiki domain knowledge and conversation archives; cross-link them only when useful.
